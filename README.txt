# Weather Program (Java Port)

## How to Compile and Run

1. Place both Weather.java and Main.java in the same directory.
2. Compile both:
    javac Weather.java Main.java
3. Run the program:
    java Main

## What It Does
- Prints the weather description, today's weather (Sunday), and a weekly weather summary with highs/lows, averages, and per-day breakdown.
